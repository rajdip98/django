Recommended practice

Change both shared secrets before this installation is public. The fallbacks live in app/config/settings.py, readable by anyone with the source. Set PLATFORM_DEFAULT_PASSWORD and PANEL_DEFAULT_PASSWORD as environment variables, then rotate the passphrase here.
  • Rotate the passphrase whenever an administrator leaves.
  • Review the audit log for “Elevated to Super Admin” and “Elevation refused”.
  • Keep platform accounts to the few people who genuinely run the installation.
