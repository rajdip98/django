How administrator accounts work

  • Every new account starts on the shared default password and must change it before it can use the panel at all.
  • An administrator belongs to one website. A Super Admin manages that website fully; an Admin manages its content only.
  • Neither can open this platform panel with their own account — that needs the platform passphrase, and every attempt is recorded.
  • Reset password puts an account back on the default and re-arms the forced change. Use it when someone is locked out.
