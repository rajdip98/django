Turning the backend on

Your project already contains it, in the backend folder. It needs hosting that can run Python — many shared hosts can, through cPanel.

  1. In cPanel, look for Setup Python App. If it is not there, ask your host whether Python applications are available on your plan.
  2. Create an application on Python 3.11 and upload backend/python-api into it.
  3. Create a MySQL database and user in cPanel, then set the application's DATABASE_URL environment variable to mysql://user:password@localhost:3306/dbname.
  4. Set your own passwords in the environment before the first sign-in: PANEL_DEFAULT_PASSWORD, PANEL_ELEVATION_SECRET, PLATFORM_DEFAULT_PASSWORD, and a fresh DJANGO_SECRET_KEY.
  5. From the application's terminal, run python manage.py migrate, then python manage.py bootstrap_panel and python manage.py bootstrap_platform.
  6. Set the application URL to /adminpanel. These two pages then step aside and the real panels open in their place.

backend/README.md has the complete instructions, and TRD.md describes what each service does.

A word about passwords

The three default passwords shipped with the project are written in files that anyone with the download can read. Treat them as public. Set your own through the environment variables listed above before the first sign-in.

Each administrator is then forced to replace their own password the first time they sign in, and reaching Super Admin functions needs a separate passphrase that expires after thirty minutes.
