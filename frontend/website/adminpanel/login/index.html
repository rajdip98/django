Is this secure?

This page has no password, and could not usefully have one. Anyone can read the source of a page on a static website, so a password typed here would be visible to them.

That is safe, because this editor cannot change your website. It only prepares a file. Publishing it means uploading to your host — and that needs your hosting login, which nobody else has.

For real accounts, permissions and an audit log, run the backend — see the panel on the left.

Want the full admin system, with logins?

The complete panel — multiple administrators, roles, file uploads, event and member management, and an audit log — is in the backend folder of your project. It needs a host that can run Python.

  1. In cPanel, look for Setup Python App. If it is there, your host can run it.
  2. Create an application, Python 3.11, and upload backend/python-api.
  3. Create a MySQL database in cPanel and set DATABASE_URL in the application's environment variables.
  4. Run python manage.py migrate and python manage.py bootstrap_panel from the panel's terminal.
  5. Point the application at /adminpanel. This page then steps aside and the real one opens.

Full instructions are in backend/README.md. If your host has no Python option, the offline editor above covers the header and footer, and the page text can be edited directly in the .html files.
